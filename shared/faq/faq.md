# Chord Practice FAQ

## General

### What is Chord Practice?
Chord Practice helps you build consistency switching between guitar chords using timed sessions and multiple practice modes.

### Do I need an account to use the app?
No. You can use core features without signing in.

### Why should I sign in?
Sign-in is recommended for Pro users because it enables sync across devices.

## Sessions

### How do I create a session?
1. Open the Home screen.
2. Tap the + button.
3. Choose chords, mode, and duration.
4. Tap Save.

### Can I edit an existing session?
Yes. Open a saved session from Home, make changes, and tap Save.

### What do the session type filters on Home do?
The filter chips at the top show only sessions of the selected type:
- All
- Interval
- Perfect
- Sequence
- Count

### Why is my session order changing?
Sessions are sorted by most recently used first. If two sessions have no recent run activity, newer created sessions appear first.

## Practice Modes

### What is Interval mode?
The app switches chords automatically at a set interval.

### What is Perfect Chord mode?
The app uses microphone chord detection and advances when the current chord is played cleanly.

### What is Chord Sequence mode?
You build an ordered timeline of chords (repeats allowed). The sequence advances one chord per bar in 4/4 based on BPM.

### What is Count mode?
You switch chords manually and record how many full cycles you completed when the timer ends.

## Duration, Tempo, and Controls

### Can I quickly change session duration?
Yes. On Session Duration, tap + or - for single steps, or press and hold for continuous faster changes.

### What BPM values are supported in Sequence mode?
BPM supports 0.5 increments between 40 and 200 (for example: 117, 117.5, 118).

### Can I quickly change BPM?
Yes. Tap + or - for 0.5 changes, or press and hold for continuous changes that accelerate over time.

## History

### Where can I view session history?
Tap the history icon on any session in Home.

### What does history include?
History includes run time and mode-specific results such as:
- Interval: number of switches
- Perfect Chord: completed chords
- Chord Sequence: loops completed and BPM
- Count: recorded cycle count

### Is history limited on free tier?
Yes. Free tier shows up to 10 most recent runs per session. Older runs remain stored but are hidden unless you upgrade.

## Subscriptions and Pro

### What does Pro unlock?
Pro unlocks:
- Full chord library (including barre shapes)
- Perfect Chord mode
- Chord Sequence mode
- Unlimited sessions and full visible history
- Cross-device sync

### Can free users create unlimited sessions?
No. Free tier is limited to 3 saved sessions.

### How do I restore purchases?
Open the paywall and use Restore Purchases.

### How do I manage or cancel my subscription?
Subscriptions are managed by Apple through your Apple ID subscription settings.

## Editing Mode Type Safely

### What happens if I change a saved session’s mode?
You will see a confirmation dialog explaining potential impacts.

### Why does the app ask me to confirm mode changes?
Changing mode can affect how the session behaves and how you interpret run history.

### What choices are shown when changing mode on a saved session?
- Cancel
- Save as New
- Change Existing

### When should I use Save as New?
Use Save as New when you want to preserve the existing session configuration/history context and create a separate variant.

### Why does switching to Count mode change duration?
Count mode resets duration to 1 minute by design.

## Troubleshooting

### I cannot start practice. Why?
Most often the session has no required chord setup:
- Sequence mode needs at least one sequence step.
- Other modes need at least one selected chord.

### My purchase did not unlock Pro immediately.
Try these steps:
1. Confirm you are signed in.
2. Use Restore Purchases.
3. Reopen the app.
4. If needed, contact support.

### I changed mode and my chord setup looks different.
Sequence mode and non-sequence modes use chord data differently. You may need to rebuild your setup after switching.
